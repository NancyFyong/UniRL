# FlashAttention-2. HPSv3's create_model_and_processor (hpsv3/train.py, also on
# the inference path) does `try: import flash_attn` and then loads Qwen2-VL with
# attn_implementation="flash_attention_2" whenever the import succeeds and
# disable_flash_attn2 is False (its default) — otherwise it silently falls back
# to SDPA. So the *presence of this package* is what flips the backbone onto
# flash attention; no code change is possible/needed. PyPI's flash-attn builds
# from source (needs nvcc, minutes-to-fail), so pin a prebuilt wheel matching
# this venv exactly: cp312 / torch2.12 / cu130 (Hopper sm_90). FA3 does NOT fit
# here — its import name is flash_attn_interface and HPSv3 hardcodes the FA2
# string, so an FA3 wheel would be ignored.
